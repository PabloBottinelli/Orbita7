# Órbita7

Sitio web desarrollado para **Órbita7**, un emprendimiento de servicios audiovisuales y técnicos con drones.

La web funciona como presentación comercial del negocio: muestra sus servicios mediante videos de ejemplo, explica su modalidad de trabajo y ofrece canales de contacto para potenciales clientes.

## Sobre la web

Desarrollé una página de presentación de servicios con diseño responsive y navegación por secciones. La versión móvil utiliza un menú desplegable de Bootstrap.

El sitio presenta distintas aplicaciones de los vuelos con drones, entre ellas cobertura de eventos, videos institucionales, monitoreo de obras, recorridos de propiedades, inspecciones, contenido para redes sociales, agricultura y mapeo geográfico.

El formulario HTML envía consultas a través de **FormSubmit**, un servicio externo.
